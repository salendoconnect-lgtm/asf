END EXPANSION — СБОРКА В ОДИН КЛИК

1. Установи Java 17, если её ещё нет.
2. Распакуй весь архив в любую папку.
3. Дважды кликни build.bat.
4. При первом запуске скрипт сам скачает Gradle 8.6.
5. Затем он соберёт мод и создаст:

   end-expansion-1.0.0.jar

6. Перемести этот JAR в:

   %APPDATA%\.minecraft\mods

В папке mods также должен быть Fabric API для Minecraft 1.20.1.

Важно: для скачивания Gradle и зависимостей Minecraft/Fabric нужен интернет.
Не закрывай окно build.bat во время первой сборки.
